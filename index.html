Gemini Chat CLI

A cross-platform Node.js terminal client for Google Gemini. Features streaming responses, customizable ANSI color themes, and persistent chat history.

Features

  • Streaming Responses: Real-time token generation.
  • Themes: Customizable colors via CLI commands.
  • Cross-Platform: Works on Windows, Linux, macOS, Android (Termux).

Installation

1. Clone the repository:

git clone https://github.com/Kaveesha125/Gemini-Chat-CLI.git

2. Change directory:

cd Gemini-Chat-CLI

3. Install dependencies:

npm install

4. Create .env file:

cp .env.example .env

Usage

npm run ai
